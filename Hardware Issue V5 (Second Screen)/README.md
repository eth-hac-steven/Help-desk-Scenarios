### Resolving User-Ticket

1. Confirmed the laptop/External monitor was actually powered on and not just in sleep mode (checked for keyboard backlight/fan noise vs. actual wake state).
2. Checked the video cable (HDMI/DisplayPort/USB-C) connection at both the laptop and monitor ends, and reseated it.
3. Tried a different video cable and a different port on the monitor to rule out a faulty cable or port.
4. Checked the monitor's input source setting confirmed it was set to the correct input (HDMI in vs. HDMI out, etc.).
5. Used the Windows key + P (Project) shortcut to cycle display modes (Duplicate/Extend/Second screen only), in case the output was routed elsewhere.if this was the case;
  - It was most likely set to pc screen only 
  - So change it to Extended
6. Tested the monitor with another known-working laptop to isolate whether the fault was the monitor or the original laptop's graphics output.
7. Escalated to hardware replacement/repair if the monitor itself was confirmed faulty.
